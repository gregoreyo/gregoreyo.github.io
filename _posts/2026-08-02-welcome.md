This is the first post on the new site — a good spot to explain what you'll find here.

Every post in this blog is a plain markdown file living in `_posts/`, named `YYYY-MM-DD-title.md`. Jekyll (which GitHub Pages runs automatically) turns each one into a page — no build step to manage yourself.

To write a new post, copy this file, rename it with today's date and a slug, and replace the front matter and content:

```markdown
---
title: "Your Post Title"
tags: [tag1, tag2]
---

Your content here, in markdown.
```

It'll show up on the [blog index]({{ '/blog/' | relative_url }}) automatically, newest first.
